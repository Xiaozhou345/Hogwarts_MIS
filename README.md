# 霍格沃茨管理信息系统(MIS)

本项目为关系数据库管理信息系统实训作业。系统基于B/S架构，除实现基础的用户管理(注册/登录)外，重点设计并实现了核心业务流程：**学院杯积分动态管理**。

## 核心技术栈
* **前端**:待定(采用B/S架构，通过浏览器访问)
* **后端**:Python
* **数据库**:MySQL(采用InnoDB引擎，利用触发器与外键约束保证数据一致性)

## 团队成员与分工
本项目由4人小组共同完成：
* **组长(Noa)**:负责项目统筹、数据库底座设计、后端基础架构搭建及用户鉴权API开发。
* **组员1(前端)**:负责全部浏览器端页面UI绘制、表单验证及前后端接口数据联调。
* **组员2(后端)**:负责教授端工作台API(核心业务数据写入与积分工单生成)。
* **组员3(后端)**:负责学生端及公共大厅API(多表联合聚合查询与排行榜数据读取)。

## 快速启动指南

### 1.数据库初始化
1.在本地环境安装MySQL。
2.使用MySQL客户端(如Workbench)打开并运行根目录下的`init.sql`文件。
3.该脚本会自动完成建库建表(`house`,`sys_user`,`point_log`)、注入基础学院数据，并创建自动化统计总分的数据库触发器(`trg_after_point_insert`)。

### 2.后端环境配置
请确保本地已配置Python环境，然后按照以下步骤操作：

**步骤一:安装依赖**
在项目根目录打开终端，执行以下命令同步依赖库：
```bash
pip install -r requirements.txt
```

**步骤二:配置环境变量**
1.复制根目录下的`.env.example`文件，并重命名为`.env`。
2.修改文件内部变量为你自己本地的数据库配置：
```ini
#DatabaseConfiguration
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_local_password
```
*注意:`.env`文件已加入忽略名单，切勿将真实密码提交至远程仓库。*

本项目严格采用前后端分离开发模式。所有数据交互规范(请求路径、参数格式、JSON响应体)请统一参阅根目录下的标准文档：
