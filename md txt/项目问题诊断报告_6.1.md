### 问题1：课程表时间段显示逻辑错误

**位置**: `frontend/js/student-courses.js:287-288`

**问题描述**：
前端课程表渲染时，使用简单的字符串比较来判断课程是否在某个时间段：
```javascript
const course = courses.find(c => c.start_time <= time && c.end_time > time);
```

**根本原因**：
1. 后端返回的时间格式可能是 `"09:00:00"` 或 `"9:00:00"`（timedelta转字符串）
2. 前端的 `timeSlots` 是 `['09:00', '10:00', ...]`（无秒）
3. 字符串比较 `"09:00:00" <= "09:00"` 结果错误（字典序比较）
4. 导致课程无法正确覆盖对应的时间格子

**影响**：
- 学生看到的课程表与实际课程时间不符
- 可能导致学生错过上课时间

**正确做法**：
应该将时间字符串转换为分钟数进行数值比较：
```javascript
function timeToMinutes(timeStr) {
  const [h, m] = timeStr.split(':').map(Number);
  return h * 60 + m;
}
const courseStart = timeToMinutes(course.start_time);
const courseEnd = timeToMinutes(course.end_time);
const slotTime = timeToMinutes(time);
// 判断：slotTime >= courseStart && slotTime < courseEnd
```

**修复优先级**: 🔴 最高

### 问题2：教师记录课堂表现时，学生列表未过滤

**位置**: `frontend/js/professor-courses.js:306-318`

**问题描述**：
教师点击"记录课堂表现"时，学生下拉列表显示的是**所有学生**（`allStudents`），而不是**已选该课程的学生**。

**代码问题**：
```javascript
function openPerformanceModal(courseId) {
  document.getElementById('performanceCourseId').value = courseId;
  
  const studentSelect = document.getElementById('performanceStudent');
  studentSelect.innerHTML = '<option value="">-- 请选择学生 --</option>';
  allStudents.forEach(student => {  // ❌ 错误：显示所有学生
    const option = document.createElement('option');
    option.value = student.user_id;
    option.textContent = `${student.username} (学院ID: ${student.house_id})`;
    studentSelect.appendChild(option);
  });
  
  document.getElementById('performanceModal').style.display = 'flex';
}
```

**影响**：
- 教师可能误选未选课的学生
- 后端虽然会拦截（`professor_api.py:385-391`检查选课记录），但用户体验差
- 教师需要记住哪些学生选了课，增加操作负担

**正确做法**：
应该调用 `getEnrolledStudents(courseId)` 获取该课程的选课学生列表：
```javascript
async function openPerformanceModal(courseId) {
  document.getElementById('performanceCourseId').value = courseId;
  
  const studentSelect = document.getElementById('performanceStudent');
  studentSelect.innerHTML = '<option value="">-- 加载中 --</option>';
  
  // 获取该课程的选课学生
  const res = await getEnrolledStudents(courseId);
  if (res.code === 200 && res.data) {
    studentSelect.innerHTML = '<option value="">-- 请选择学生 --</option>';
    res.data.forEach(student => {
      const option = document.createElement('option');
      option.value = student.student_id;
      option.textContent = `${student.student_name} (${student.house_name})`;
      studentSelect.appendChild(option);
    });
  }
  
  document.getElementById('performanceModal').style.display = 'flex';
}
```

**修复优先级**: 🔴 最高

### 问题3：学生端课堂表现无法显示

**位置**: `frontend/js/student-courses.js:317-358`

**问题描述**：
学生端加载课堂表现时，代码期望 `res.data` 是数组，但后端返回的是对象：
```javascript
// 前端期望：
if (res.code === 200 && res.data && res.data.length > 0) {
  res.data.forEach(perf => { ... });
}

// 后端实际返回（student_api.py:397-401）：
return jsonify({
    "code": 200,
    "msg": "success",
    "data": {"performances": performances, "total": total, "page": page, "limit": limit}
})
```

**根本原因**：
前端期望 `data` 是数组，但后端返回的是包含 `performances` 数组的对象（分页格式）。

**影响**：
- 学生端"课堂表现"标签页永远显示"还没有课堂表现记录"
- 即使教师添加了表现，学生也看不到

**正确做法**：
前端应该访问 `res.data.performances`：
```javascript
if (res.code === 200 && res.data && res.data.performances && res.data.performances.length > 0) {
  res.data.performances.forEach(perf => { ... });
}
```

**修复优先级**: 🔴 最高

### 问题5：课程详情选课人数未实时更新

**位置**: 数据库查询缓存问题

**问题描述**：
学生选课后，课程详情页面的"选课人数"不会立即更新，需要刷新页面。

**根本原因**：
这不是代码逻辑错误，而是前端缓存问题。学生选课成功后：
1. `enrollCourse()` 成功
2. 调用 `loadAvailableCourses()` 刷新可选课程列表
3. 但如果用户之前打开过某课程的详情，该详情数据已缓存在前端

**影响**：
- 用户体验不佳
- 可能误导学生认为选课失败

**正确做法**：
选课成功后，清除相关课程的详情缓存，或者在显示详情时重新请求：
```javascript
async function handleEnroll(courseId, courseName) {
  if (!confirm(`确定要选修《${courseName}》吗？`)) return;
  
  try {
    const res = await enrollCourse({ course_id: parseInt(courseId) });
    if (res.code === 200) {
      alert('选课成功！');
      await loadAvailableCourses();
      // 如果详情弹窗打开，刷新详情
      if (document.getElementById('courseDetailModal').style.display === 'flex') {
        await showCourseDetail(courseId);
      }
    } else {
      alert(res.msg || '选课失败');
    }
  } catch (err) {
    console.error('选课失败:', err);
    alert('网络错误');
  }
}
```

**修复优先级**: 🟡 中
