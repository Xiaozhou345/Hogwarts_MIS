## 🔍 关键技术点

### 1. 时间比较逻辑（已修复）

**错误做法**（字符串比较）：
```javascript
const course = courses.find(c => c.start_time <= time && c.end_time > time);
// "09:00:00" <= "09:00" 结果错误（字典序比较）
```

**正确做法**（数值比较）：
```javascript
function timeToMinutes(timeStr) {
  const [h, m] = timeStr.split(':').map(Number);
  return h * 60 + m;
}
const course = courses.find(c => {
  const startMinutes = timeToMinutes(c.start_time);
  const endMinutes = timeToMinutes(c.end_time);
  return slotMinutes >= startMinutes && slotMinutes < endMinutes;
});
```

### 2. 后端时间格式处理

```python
# 处理 timedelta 和 time 对象
if hasattr(start, 'total_seconds'):
    start = str(start)  # timedelta → "HH:MM:SS"
elif hasattr(start, 'isoformat'):
    start = start.isoformat()  # time → "HH:MM:SS"
else:
    start = str(start)
```
