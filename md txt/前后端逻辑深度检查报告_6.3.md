### 🟡 中等问题3：教授端显示学院ID而非学院名称

**位置**:
- 后端: `py/professor_api.py:11-26` (`/api/students`)
- 前端: `frontend/js/professor.js:35-40` (`loadStudents()`)

**问题描述**:

**后端返回**:
```python
# professor_api.py:17
SELECT u.user_id, u.username, u.house_id, h.house_name
```
返回字段: `user_id`, `username`, `house_id`, `house_name`

**前端显示**:
```javascript
// professor.js:38
option.textContent = `${student.username} (学院ID: ${student.house_id})`;
```

**问题分析**:
- 后端已经返回了 `house_name`（学院名称）
- 但前端显示的是 `house_id`（学院ID数字）
- 用户看到的是"哈利 (学院ID: 1)"而不是"哈利 (格兰芬多)"

**正确做法**:
```javascript
option.textContent = `${student.username} (${student.house_name})`;
```

## ✅ 已修复的问题回顾（6月1日修复）

- **文件**: `frontend/js/student-courses.js:263-315`

- **文件**: `frontend/js/professor-courses.js:306-332`

### 4. 教师查看选课学生名单显示错误 ✅
- **问题**: 使用 `student.username`，但后端返回 `student_name`
- **修复**: 改为 `student.student_name` 和 `student.house_name`
- **文件**: `frontend/js/professor-courses.js:283-304`

### 5. 课程详情选课人数未实时更新 ✅

## 💡 数据格式规范建议

### 建议1：统一分页格式

**所有分页接口应该返回相同格式**:
```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "items": [...],    // 统一使用 items
    "total": 100,
    "page": 1,
    "limit": 20
  }
}
```

**当前的不一致**:
- `/api/professor/logs` 返回 `data.logs`
- `/api/student/logs` 返回 `data.logs`
- `/api/student/my-performances` 返回 `data.performances`

---

### 建议2：非分页接口返回数组

**对于不需要分页的列表接口**:
```json
{
  "code": 200,
  "msg": "success",
  "data": [...]  // 直接返回数组
}
```

**例如**:
- `/api/students` ✅ 已经是直接数组
- `/api/house/ranking` ✅ 已经是直接数组
