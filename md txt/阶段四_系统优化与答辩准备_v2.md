## ✅ 已完成的Bug修复（2026-06-01）

### 修复清单
1. ✅ **学生端课堂表现无法显示**
   - 问题：前端期望 `res.data` 是数组，但后端返回 `{performances: [...], total, page, limit}`
   - 修复：前端改为访问 `res.data.performances`
   - 文件：`frontend/js/student-courses.js:323`

2. ✅ **课程表时间段显示逻辑错误**
   - 问题：使用字符串比较 `"09:00:00" <= "09:00"` 导致判断错误
   - 修复：实现 `timeToMinutes()` 函数，使用数值比较
   - 文件：`frontend/js/student-courses.js:263-315`

3. ✅ **教师记录课堂表现时学生列表未过滤**
   - 问题：显示所有学生，而不是已选该课程的学生
   - 修复：调用 `getEnrolledStudents(courseId)` 动态加载选课学生
   - 文件：`frontend/js/professor-courses.js:306-332`

4. ✅ **教师查看选课学生名单显示错误**
   - 问题：使用 `student.username`，但后端返回 `student_name`
   - 修复：改为 `student.student_name` 和 `student.house_name`
   - 文件：`frontend/js/professor-courses.js:283-304`

5. ✅ **课程详情选课人数未实时更新**
   - 问题：选课成功后，详情弹窗的选课人数不更新
   - 修复：选课成功后，如果详情弹窗打开，自动刷新详情
   - 文件：`frontend/js/student-courses.js:132-147`

6. ✅ **课程表功能分工文档缺失**
   - 问题：分工文档未包含课程表功能
   - 修复：编写《课程表功能补充分工》文档
   - 文件：`md txt/课程表功能补充分工.md`

**索引创建SQL**：

```sql
-- 1. sys_user 表索引
CREATE INDEX idx_user_role ON sys_user(role);

-- 2. point_log 表索引
CREATE INDEX idx_point_student ON point_log(student_id);

CREATE INDEX idx_point_time ON point_log(create_time);

-- 3. course 表索引
CREATE INDEX idx_course_professor ON course(professor_id);

-- 4. course_enrollment 表索引
CREATE INDEX idx_enrollment_student ON course_enrollment(student_id);
CREATE INDEX idx_enrollment_course ON course_enrollment(course_id);
CREATE INDEX idx_enrollment_status ON course_enrollment(status);
CREATE INDEX idx_enrollment_student_status ON course_enrollment(student_id, status);

-- 5. course_schedule 表索引
CREATE INDEX idx_schedule_course ON course_schedule(course_id);
CREATE INDEX idx_schedule_weekday ON course_schedule(weekday);

-- 6. class_performance 表索引
CREATE INDEX idx_performance_student ON class_performance(student_id);
CREATE INDEX idx_performance_course ON class_performance(course_id);
CREATE INDEX idx_performance_professor ON class_performance(professor_id);
CREATE INDEX idx_performance_time ON class_performance(create_time);
```

#### 任务4：准备答辩Q&A

**常见问题准备**：

1. **技术问题**
   - Q: 为什么选择Flask而不是Django？
   - A: Flask轻量级，适合小型项目，学习曲线平缓

   - Q: 如何保证密码安全？
   - A: 使用SHA256哈希加密，不存储明文密码

   - Q: 如何实现权限控制？
   - A: 使用JWT Token + 装饰器 `@role_required`

   - Q: 数据库触发器的作用是什么？
   - A: 自动维护学院总分，确保数据一致性

   - Q: 如何检测选课时间冲突？
   - A: 比较新课程与已选课程的时间区间，判断是否重叠

2. **项目管理问题**
   - Q: 团队如何分工？
   - A: 前端1人、后端3人，按模块划分

   - Q: 遇到的最大困难是什么？
   - A: 前后端数据格式不一致，通过深入代码审查发现并修复

   - Q: 如何保证代码质量？
   - A: 编写测试用例，100%测试通过率

3. **功能问题**
   - Q: 如何扩展到多学期？
   - A: 在 `course` 表添加 `semester` 字段，在查询时过滤

   - Q: 如何支持课程评价？
   - A: 新增 `course_review` 表，关联学生和课程

   - Q: 如何实现消息通知？
   - A: 新增 `notification` 表，前端轮询或使用WebSocket
