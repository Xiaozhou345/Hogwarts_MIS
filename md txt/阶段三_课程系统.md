## 五、技术要点与注意事项

### 🔥 核心难点

#### 1. 课堂表现与积分系统联动
**实现思路**:
```python
# 在 professor_api.py 中
@professor_bp.route('/api/professor/class-performance', methods=['POST'])
@token_required
@role_required(1)
def record_class_performance():
    data = request.json
    professor_id = request.user_id
    
    # 1. 先插入 point_log（积分记录）
    point_sql = """
        INSERT INTO point_log (student_id, professor_id, score_change, reason)
        VALUES (%s, %s, %s, %s)
    """
    point_log_id = execute_query(point_sql, 
        (data['student_id'], professor_id, data['score'], data['reason']),
        return_lastrowid=True
    )
    
    # 2. 再插入 class_performance（关联 point_log_id）
    perf_sql = """
        INSERT INTO class_performance 
        (student_id, course_id, professor_id, performance_type, score, point_log_id)
        VALUES (%s, %s, %s, %s, %s, %s)
    """
    execute_query(perf_sql, 
        (data['student_id'], data['course_id'], professor_id, 
         data['performance_type'], data['score'], point_log_id)
    )
    
    # 3. 触发器会自动更新 house 表的 total_points
    
    return jsonify({"code": 200, "msg": "课堂表现记录成功"})
```

#### 2. 个人课程表查询（复杂SQL）
**实现思路**:
```python
# 在 student_api.py 中
@student_bp.route('/api/student/schedule', methods=['GET'])
@token_required
@role_required(0)
def get_my_schedule():
    student_id = request.user_id
    
    sql = """
        SELECT 
            c.course_name,
            cs.weekday,
            cs.start_time,
            cs.end_time,
            cs.classroom,
            p.username AS professor_name
        FROM course_enrollment ce
        JOIN course c ON ce.course_id = c.course_id
        JOIN course_schedule cs ON c.course_id = cs.course_id
        JOIN sys_user p ON c.professor_id = p.user_id
        WHERE ce.student_id = %s AND ce.status = 1
        ORDER BY cs.weekday, cs.start_time
    """
    
    schedules = execute_query(sql, (student_id,), fetch_all=True)
    
    # 按星期分组
    week_schedule = {
        "Monday": [], "Tuesday": [], "Wednesday": [], 
        "Thursday": [], "Friday": [], "Saturday": [], "Sunday": []
    }
    
    weekday_map = {1: "Monday", 2: "Tuesday", 3: "Wednesday", 
                   4: "Thursday", 5: "Friday", 6: "Saturday", 7: "Sunday"}
    
    for schedule in schedules:
        day = weekday_map[schedule['weekday']]
        week_schedule[day].append(schedule)
    
    return jsonify({"code": 200, "data": week_schedule})
```

#### 3. 选课冲突检测
**需要检测**:
- 学生是否已选该课程
- 课程时间是否与已选课程冲突

```python
# 检查时间冲突的SQL
conflict_sql = """
    SELECT COUNT(*) as conflict_count
    FROM course_enrollment ce1
    JOIN course_schedule cs1 ON ce1.course_id = cs1.course_id
    JOIN course_schedule cs2 ON cs2.course_id = %s
    WHERE ce1.student_id = %s 
      AND ce1.status = 1
      AND cs1.weekday = cs2.weekday
      AND (
          (cs1.start_time <= cs2.start_time AND cs1.end_time > cs2.start_time)
          OR
          (cs1.start_time < cs2.end_time AND cs1.end_time >= cs2.end_time)
      )
"""
```

## 附录：数据库ER图（课程系统部分）

```
sys_user (教授)
    |
    | 1:N
    |
course -------- 1:N -------- course_schedule
    |
    | M:N (通过 course_enrollment)
    |
sys_user (学生)
    |
    | 1:N
    |
class_performance ----> point_log (外键关联)
```

**关键关系**:
- 一个教授可以教多门课程（1:N）
- 一门课程可以有多个课程安排（1:N）
- 学生和课程是多对多关系（M:N）
- 课堂表现记录关联到积分记录（1:1）
